# Credits

Virasat is MIT licensed, and stands on other people's work. Everything below is
used under its own licence. This file is generated by `npm run credits` from
`src/lib/credits.ts`, which is also what the Sources page on the site renders.

- [Tailwind CSS](https://tailwindcss.com), MIT. Styling, and the light and dark tokens.

- [Zod](https://zod.dev), MIT. Validates the rule files and the shapes the AI must return.

- [Inter and Noto Sans Devanagari](https://fonts.google.com/specimen/Noto+Sans+Devanagari), SIL Open Font Licence 1.1. The typefaces, including the Hindi one.

## For building and checking

Never reaches a visitor. These are how we know the numbers are true.

- [Vitest](https://vitest.dev), MIT. Runs the test suite.
- [ESLint](https://eslint.org), MIT. Catches mistakes before they ship.
- [Playwright](https://playwright.dev), Apache-2.0. Drives a real browser for the accessibility audit.
- [axe-core](https://www.deque.com/axe/), MPL-2.0. Finds the accessibility violations we then fix.
- [Lighthouse](https://developer.chrome.com/docs/lighthouse), Apache-2.0. Measures performance on desktop and on a throttled phone.
- [PptxGenJS](https://gitbrent.github.io/PptxGenJS/), MIT. Builds the pitch deck from code, so it rebuilds when a number changes.
- [sharp](https://sharp.pixelplumbing.com), Apache-2.0. Prepares the screenshots in the deck.
- [react-icons](https://github.com/react-icons/react-icons), MIT. Icons inside the deck.
- [tsx](https://tsx.hirok.io), MIT. Runs the audit and cost scripts.

## How this was built

Claude Code, by one developer, over the hackathon period.

The hackathon rules allow AI development tools and hold us responsible for what
we submit. Here is how we take that on:

- Every claim on this site is re-checked by one command, npm run audit, which writes down failures as readily as passes.
- The rule engine, the part that decides what a family is told to do, is covered by tests and is never decided by a model.
- The sources behind every number are listed on this page, and were read rather than taken on trust.
- Nothing here was submitted to another competition, and no code was copied from another project.

Data sources for every number on the site are listed at [/references](https://virasat-indol.vercel.app/references).
